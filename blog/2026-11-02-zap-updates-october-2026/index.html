ZAP Updates - October 2026

The ZAP Blog
Posted Monday November 2, 2026 1655 Words

Highlights

Initial OAuth2 2.0 Support

The Authentication Helper add-on (v0.43.0) now has an OAuth2 authentication method supporting the non-interactive client_credentials and password grant types. It can be configured in the desktop UI, the Automation Framework (v0.61.0 adds oauth2 support) and the API. We recommend it for APIs only; web apps with login screens should continue to use Browser Based or Client Script Authentication. Theres still more to do, and we’d like your feedback on what to prioritise. See Initial OAuth2.0 support.

Developing ZAP in the LLM Age

We’re not closing the door on new contributors, but LLMs have shifted the balance: generating code is easy, reviewing it is the bottleneck. The PR submitter is responsible for the code they propose, and PRs should be small, well tested and ideally come with Automation Framework plans. The PR template has been updated to reflect this. See Developing ZAP in the LLM Age.

Script Viewer in the Browser Extension

Version 0.3.0 of the ZAP Browser Extension lets you see a Zest script as you record it, then edit, replay (optionally step by step), load and save it, all without leaving the browser. It is available in both the full extension and the standalone Recorder, and is included in Client Side Integration v0.34.0. See View, edit, and replay your recorded Zest scripts.

Detecting PHP2Shell

The new passive Server Side Technology Version with Known Vulnerabilities rule (Passive scanner rules v77) checks technology versions disclosed in response headers against known vulnerabilities, initially PHP versions, so ZAP can flag PHP2Shell (CVE-2026-109618 / CVE-2026-109619) without sending any extra requests. See Detecting PHP2Shell and Other PHP Vulnerabilities with ZAP.

ZAP Usage Is Still Growing

The ZAP statistics show that ZAP usage is still increasing, and that we’ve had more direct downloads and Docker pulls than ever before. Thank you to everyone who uses and supports ZAP!

Ongoing Work

Global Scan Policy Manager

Work continues on the Global Scan Policy Manager. This is a large change that touches many areas of ZAP, but it is a key change that we want to get into the next ZAP release. You can try it out by building and running ZAP from the source code.

LLM Support

The /docs/desktop/addons/llm-support/automation/#job-llm-config Automation Framework job has been released in the LLM Support add-on (v0.1.0). LLM assisted authentication in the Authentication Helper has landed, but has not been released yet. We expect to release it soon.
