ZAP Updates - August 2026

The ZAP Blog
Posted Tuesday September 8, 2026 1237 Words

Highlights

Retiring the AJAX Spider and DOM XSS Add-ons

Since the Client Spider became our recommended crawler in July, we’re now taking the next step: the AJAX Spider and DOM XSS Active Scan Rule add-ons are being removed from the nightly and weekly (Docker) releases. The add-ons will be removed from the weekly release starting from the week starting on the 14th September.

The DOM XSS add-on is being retired for a similar reason: the OWASP PTK add-on finds DOM XSS far more effectively, so it’s now the better option for this kind of testing.

This only affects what ships by default - if you still rely on the AJAX Spider job in the Automation Framework or via the API, nothing breaks: those will keep working, just backed by the Client Spider instead. Both the AJAX Spider and DOM XSS add-ons will remain available to install from the Marketplace if you still need them, but we’d recommend switching to the Client Spider and OWASP PTK respectively, since they’re more effective.

The LLM Support Add-on Has Landed

After being previewed in the last monthly update, the LLM Support add-on officially launched in August - see the dedicated blog post for the full details. It’s an optional, opt-in add-on that connects ZAP to an LLM of your choice (Claude, Gemini, Azure OpenAI, Ollama, or OpenAI Compatible endpoints), powering a tabbed chat panel and integrating with the MCP add-on so the LLM can call ZAP’s tools directly.

It’s also already powering AI-assisted features in two other add-ons: OpenAPI Support gained an LLM-driven OpenAPI importer, and Alert Filters gained a “Review using LLM/AI” action for re-assessing alert confidence.

Ongoing Work

Splitting Authentication and Verification

Following on from last month, the work to split the “verification” strategy out from the authentication method itself has continued to progress in ZAP’s core: poll verification now supports a configurable HTTP method, existing headers can be overridden during poll verification. Everything remains backwards compatible.
