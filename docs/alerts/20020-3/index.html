Summary

The server disclosed the version of a server side technology it is running via an HTTP response header, and that version is affected by known vulnerabilities. The version, header and vulnerabilities, listed by severity, are given in the other info. See the references for the details of each. Note that some distributions backport security fixes without changing the version number, so check whether the fixes have actually been applied before reporting these as confirmed.

Solution

Upgrade Apache HTTP Server to a supported version which includes fixes for the listed vulnerabilities. Also configure the server not to disclose its version, e.g. by setting "ServerTokens Prod" and "ServerSignature Off".

Other Info

The server disclosed that it is running Apache HTTP Server version 2.4.49 via the "Server" HTTP response header. 1 known vulnerabilities: 1 critical, 0 high, 0 medium, 0 low. Critical: CVE-2021-41773
